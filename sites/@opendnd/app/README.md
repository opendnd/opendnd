# @opendnd/app

The application: sign in, open a world, and read or author any resource through pages built from the ontology the API describes. The map, the wiki, characters and campaigns are features of it.

Part of [OpenDnD](https://github.com/opendnd/opendnd), an open ontology, headless API and toolset for building fictional worlds. A project of [OpenHI](https://openhi.org).

Documentation: https://docs.opendnd.org/packages/app/
