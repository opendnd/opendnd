# @opendnd/terrain

A world's geography as data: reading the shapes out of a drawn map, and, from a coastline, the land beneath it. The same field however it arrived, so a world someone drew and a world nobody has drawn yet are the same kind of thing.

Part of [OpenDnD](https://github.com/opendnd/opendnd), an open ontology, headless API and toolset for building fictional worlds. A project of [OpenHI](https://openhi.org).

Documentation: https://docs.opendnd.org/packages/terrain/
